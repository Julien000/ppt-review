# 领域严谨性核查清单（计算机 / AI / CV / AI安全）

逐页审查时对照本清单。目标：术语零误用、因果语言与证据强度匹配、领域特有论证要件齐全。

## 一、术语精度表

常见误用 → 正确区分（PPT 中出现左侧用法即标记）：

| 高频误用/混淆 | 审查要点 |
|---|---|
| 准确率 / 精确率 / 召回率 | Accuracy（全体判对比例）、Precision（预测为正中真为正）、Recall（真为正中被检出）三者不得互换；中文语境"准确率"常被滥用指代 Precision |
| 检测 / 分类 / 识别 | Detection 含定位（框/掩码）；Classification 只判类别；Recognition 常指含身份判定的整体任务。混用即概念错误 |
| 对抗样本 / 对抗攻击 / 对抗训练 / 对抗扰动 | 依次为：恶意输入、攻击行为、防御方法、加性扰动。方向性不得颠倒（对抗训练是防御不是攻击） |
| 鲁棒性 / 安全性 | Robust 必须绑定威胁模型才有意义；鲁棒 ≠ 安全（安全还含隐私、误用等维度） |
| 机器学习 / 深度学习 / 人工智能 | 层级包含关系 ML ⊂ AI、DL ⊂ ML，不得以大代小或以小代大 |
| 泛化性 / 鲁棒性 / 迁移性 | 泛化=分布内新样本；鲁棒=受扰动的输入；迁移=跨任务/跨域。另注意对抗样本的"迁移性（transferability）"特指跨模型攻击成功率 |
| "AI 安全"的所指 | AI 系统自身安全（对抗鲁棒性/后门/投毒/越狱/提示注入）≠ AI for Security（用 AI 做安全）≠ AI 伦理（公平/隐私/可解释）。页面声称"AI 安全"须明确所指分支 |
| 微调 / 提示工程 / RAG | 三者是不同的模型适配层级，不得混为一谈 |
| mAP@0.5 与 mAP@0.5:0.95、Top-1 / Top-5、IoU / mIoU | 指标须绑定数据集、阈值与协议，缺一即量化缺失 |
| "实时" | 必须给出 FPS 与硬件平台，否则删除该词 |
| "端到端" | 指可微联合优化，非"输入直接到输出"的字面义 |
| 幻觉 / 对齐 / RLHF / 对齐税 | LLM 安全术语，须定义后使用，不得口语化带过 |

## 二、因果与论证语言规范

| 用词 | 使用条件 |
|---|---|
| 证明 / prove | 仅限数学定理与形式化验证。实验结果只能"表明 / 验证 / 支持假设" |
| 导致 / cause | 需机制说明或消融证据；仅有相关性时用"与…相关 / 伴随出现" |
| 显著 / significant | 默认指统计显著性，须附检验方法与 p 值；若为口语义改说"提升 X%（基准 B 上）" |
| 解决了 X | 仅当 X 被完整定义且方法在 X 的全部设定下验证时可用；否则"缓解 / 在 Y 设定下改进" |
| 首次 / 首个 | 须有文献检索支撑。无支撑时建议删除——这是答辩中最容易被击穿的声明 |
| SOTA | 须指明基准、数据集、时间点、评测协议 |
| 大幅 / 显著提升 / 全面超越 | 一律追问数字；无数字即"量化缺失" |

## 三、AI 安全领域专项（导师审查最严之处）

1. **威胁模型三要素**：任何鲁棒性声明必须回答——攻击者知识（白盒/黑盒/灰盒）、攻击能力（ε 预算、迭代次数、查询次数）、攻击目标（无目标/有目标）。缺任一项，该页鲁棒性结论不成立。
2. **自适应攻击（adaptive attack）**：防御评估若仅报固定攻击（如 PGD）下的结果，属不可靠证据——须标注"未评估自适应攻击"。
3. **后门 / 投毒**：须说明攻击者假设（数据集访问权、投毒比例、触发器可见性、是否假设可修改训练流程）。
4. **LLM 安全**：越狱、提示注入、红队等术语须定义后使用；对齐效果的代价（对齐税、通用能力下降）若未讨论，属论证单侧性。
5. **公平比较**：防御/方法对比须对齐计算预算（FLOPs、参数量、训练数据量），否则对比无效。

## 四、CV 领域专项

1. 指标须绑定数据集与协议（训练/验证/测试划分、数据增强、评测代码来源）。
2. 可视化结果（热力图、检测框示例）不得作为主要证据，须有定量结果支撑；定性图挑选偏差须提示。
3. 零样本/小样本声明须说明训练集与测试集的域差距，否则"零样本"名不副实。
4. "超过人类水平"须引用人类基准的来源与评测协议。
5. 视频任务须交代时序协议（离线/在线、是否使用未来帧）。

## 五、通用机器学习论证要件

1. "X 组件有效"的归因须有消融实验支撑（去掉 X 的对照）。
2. Baseline 是否充分；引用原论文数字还是复现数字，须注明。
3. "收敛更快"须有收敛曲线或达到目标指标所需 epoch 数的对照。
4. 随机种子与方差：关键结论须报多种子均值±标准差，或说明单次运行的局限。
5. 超参敏感性：核心超参（如 ε、学习率、温度）是否做敏感性分析。

## 使用方式

逐页审查（工作流第三步）时，对每页出现的术语与断言逐项扫描本清单；
发现命中项，记为对应问题性质（概念错误属🔴，量化缺失属🟡），
并在建议中给出符合右列要求的改写方向。
